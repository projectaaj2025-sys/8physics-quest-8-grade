# Физика-Квест: Тепловой и электрический щит

Готовый набор файлов для публикации образовательной HTML-игры по физике 8 класса на GitHub Pages.

## Что внутри

- `index.html` — главная страница сайта, именно этот файл откроется на GitHub Pages.
- `documents/physics-quest-8-grade.html` — копия исходного HTML-документа с удобным именем.
- `.nojekyll` — служебный файл, чтобы GitHub Pages публиковал статические файлы без обработки Jekyll.
- `GITHUB_UPLOAD_INSTRUCTIONS.md` — краткая инструкция по загрузке и публикации.

## Быстрый запуск локально

Откройте `index.html` в браузере двойным кликом или через локальный сервер.

## Публикация

Загрузите содержимое этого архива в новый репозиторий GitHub и включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → /root**.
