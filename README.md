# Папка для PDF-конспектов (необязательно)

Игра умеет отдавать ученикам PDF-конспекты уроков (кнопки «Скачать конспект»
в теории и на экране уровней). Чтобы они работали, положите в эту папку файлы
с такими именами:

| Язык | Имя файла |
|---|---|
| Русский | `Fizika_8_klass_konspekt_russkiy.pdf` |
| English | `Physics_Grade_8_Notes_English.pdf` |
| Қазақша | `Fizika_8_synyp_konspekt_kazaksha.pdf` |

Дополнительные имена, которые игра тоже подхватывает:
`Физика_8_класс_Конспект_РУС.pdf`, `Physics_Grade8_Notes_ENG.pdf`,
`Физика_8_сынып_Конспект_ҚАЗ.pdf`.

Если PDF-файлов нет — игра полностью работоспособна, просто кнопки скачивания
конспектов не будут ничего скачивать.
