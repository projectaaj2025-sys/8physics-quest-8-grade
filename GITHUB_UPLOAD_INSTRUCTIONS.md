# Инструкция: как опубликовать архив на GitHub Pages

1. Зайдите на https://github.com и войдите в свой аккаунт.
2. Нажмите **New repository**.
3. Назовите репозиторий, например: `physics-quest-8-grade`.
4. Выберите **Public** — для бесплатной публикации через GitHub Pages публичный репозиторий подходит проще всего.
5. Нажмите **Create repository**.
6. Распакуйте этот архив на компьютере.
7. В созданном репозитории нажмите **Add file → Upload files**.
8. Перетащите в окно загрузки все файлы и папки из распакованного архива:
   - `index.html`
   - `documents/`
   - `.nojekyll`
   - `README.md`
   - `GITHUB_UPLOAD_INSTRUCTIONS.md`
9. Нажмите **Commit changes**.
10. Откройте **Settings → Pages**.
11. В разделе **Build and deployment** выберите:
    - **Source:** `Deploy from a branch`
    - **Branch:** `main`
    - **Folder:** `/root`
12. Нажмите **Save**.

Через 1–3 минуты сайт будет доступен по адресу:

`https://ВАШ_ЛОГИН.github.io/physics-quest-8-grade/`

Если название репозитория будет другим, замените `physics-quest-8-grade` в ссылке на фактическое название репозитория.

## Если нужно опубликовать вместо вас

Для прямой публикации нужен доступ к вашему GitHub-репозиторию. Без доступа к аккаунту я могу подготовить только готовый архив и инструкцию.
